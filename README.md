# FX Fundamental Technical Engine

Status: project foundation pending Phase 00 contract freeze.

This project will research and implement a hybrid FX system in which:

- a point-in-time fundamental engine produces `LONG_BASE`, `SHORT_BASE`, or
  `FLAT` pair bias;
- a separate mechanical technical strategy controls entries and exits;
- historical bias is replayed through an Exness MetaTrader 5 backtest;
- approved research candidates progress to Telegram notifications and an MT5
  demo-account forward test.

The repository will be initialized after its remote GitHub URL is available.
